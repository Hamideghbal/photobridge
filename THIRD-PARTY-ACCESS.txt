Access export uses Jackcess 4.0.7, Apache Commons Lang 3.14.0, Commons Logging 1.3.0 and Gson 2.10.1 under Apache License 2.0. Original license/notice files are retained inside each jar. The build downloads Eclipse Temurin OpenJDK 21 JRE for Windows x64; its original legal directory and GPLv2 + Classpath Exception notices remain bundled with the runtime. No Microsoft Access/Office installation is required to CREATE the exported .accdb file. Viewing/editing the file can be done in Microsoft Access. PhotoBridgeAccess.java is the project-owned exporter source; the bundled helper jar corresponds to that source.
