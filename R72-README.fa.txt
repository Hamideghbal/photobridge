PhotoBridge R72 — جایگزینی کامل برنامه ویندوز لابراتوار

- کلاینت قدیمی لابراتوار و فایل‌های نصب Preview قبلی از بسته وب حذف شدند.
- برنامه جدید Lab Desktop روی همان معماری Store Desktop ساخته شده: Electron امن، SQLite محلی با WAL، Safe Storage، Tray، اجرای خودکار ویندوز، بکاپ روزانه، صف آفلاین و همگام‌سازی خودکار.
- ظاهر برنامه همان پنل واقعی لابراتوار است و UI بدون نصب مجدد برنامه از سرور به‌روز می‌شود.
- درخواست‌های GET لابراتوار در SQLite کش می‌شوند تا صفحات بازشده قبلی بدون اینترنت قابل استفاده باشند.
- عملیات JSON قابل صف در حالت آفلاین ذخیره می‌شوند و بعد از اتصال ارسال می‌شوند؛ عملیات حساس مثل آپلود فایل، پرداخت، تغییر رمز و سرویس AI همچنان اینترنت می‌خواهند.
- API دانلود برنامه لابراتوار دیگر از Installer قدیمی داخل پروژه استفاده نمی‌کند. آخرین EXE از Object Storage و پنل ادمین مدیریت می‌شود، دقیقاً مشابه برنامه فروشگاه.
- در پنل ادمین، کارت «برنامه ویندوز لابراتوار» اضافه شده تا EXE و شماره نسخه بارگذاری/جایگزین شود.
- سورس Windows app در apps/lab-desktop قرار دارد. برای ساخت Installer روی Windows: npm ci سپس npm run dist:unsigned (نسخه امضاشده با گواهی Code Signing ساخته شود).
