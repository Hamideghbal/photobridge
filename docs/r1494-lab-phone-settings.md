# R1494 — lab phone settings navigation and tariff access

On lab phones, the photographer/invitation/collaboration menu stays at the top of its settings scroll area. The member list uses a compact two-column information layout and puts initial-debt and account-status actions in separate touch targets. Status labels no longer dominate the card.

The settings category/subsection pickers receive a scrollable option menu on phones, and the print/binding plus walk-in tariff lists retain vertical scrolling within the available screen area. The picker menu class is conditional on the existing lab-phone detector; Windows and desktop DOM remain unchanged. No server values, tariff data, or APIs change.
