# PhotoBridge Lab 1.0.79 — نمایشگر مالی آفلاینِ بکاپ

**مبنای کد:** شاخه `build/lab-1.0.79-queue-header-layout-reset` (کامیت `67529a65eb8c9fec1d6db80f0af4628ab1a7bff1`). شماره نسخه در `package.json` عمداً **1.0.79** مانده است. **هیچ فایل EXE، نصب‌کننده یا بیلد ویندوز در این بسته تولید نشده است.**

## تغییرات محدود این بسته

- افزودن `backup-finance-viewer.cjs` و `backup-finance-viewer-template.html` برای ساخت فایل مستقل `مشاهده بکاپ.html` هنگام هر بکاپ جدید.
- اضافه‌کردن نام این فایل به `manifest.json` و بررسی اندازه و SHA-256 آن، در کنار بکاپ قبلی `data.sqlite` و `finance.accdb`.
- نمایش وضعیت ساخته‌شدن نمایشگر در صفحه پشتیبان‌گیری.
- تست‌های نمایشگر و بکاپ. کدهای سفارش، چاپ، صف آماده‌تحویل، دیتابیس اصلی، Access، بازیابی و فایل‌های `verified-ui` تغییری نکرده‌اند.

## شباهت به بخش امور مالی سایت

نمایشگر از کد و نام بخش‌های مالی سایت داخل `verified-ui` الگو گرفته است: هدر فوتوبریج، تب‌های «فاکتورها»، «دریافت‌ها»، «حساب معین»، انتخاب عکاسی، جستجو، بازه تاریخ، دکمه‌های «امروز»، «نمایش همه» و «نمایش بازه»، کارت‌های فاکتور، ردیف‌های دریافت، جدول معین با بدهکار/بستانکار/مانده، «نمایش خلاصه/نمایش با جزئیات»، مرتب‌سازی تاریخ، چاپ و خروجی CSV. فونت Vazirmatn اصلی پروژه داخل HTML جاسازی می‌شود تا بدون اینترنت هم نمایش داده شود.

**محدودیت:** این یک نمایشگر فقط‌خواندنی از اطلاعات موجود در همان بکاپ محلی است، نه خود سایت زنده. دکمه‌های «ثبت فاکتور دستی»، «ثبت پرداخت»، «ثبت تخفیف»، «اصلاحیه» و «ثبت در حسابداری» برای حفظ ایمنی غیرفعال هستند. وضعیت ثبت در حسابداری، اگر در مدل بکاپ ذخیره نشده باشد، به‌صورت نامشخص نمایش داده می‌شود، نه به‌صورت مقدار ساختگی. کپی HTML به رایانه دیگر، تمام اطلاعات همان لحظه را بدون اتصال نشان می‌دهد.

حساب معین از `CustomerStatement` موجود در **نسخه 1.0.79** استخراج می‌شود تا مانده‌ها با دفتر معین همان برنامه هماهنگ باشند؛ از جمع خام ردیف‌های دفتر دوبل استفاده نشده است. اگر اطلاعاتی فقط در سایت وجود داشته و روی ویندوز همگام نشده باشد، در بکاپ محلی هم وجود نخواهد داشت.

## ساخت نصب‌کننده روی ویندوز توسط خودتان

در ویندوز با Node.js 22 و محیط بیلد خودتان:

```powershell
cd "مسیر-استخراج-سورس"
npm ci --no-audit --no-fund
npm run dist:unsigned
```

خروجی نصب‌کننده در پوشه `release` خواهد بود. برای بیلد امضاشده، تنظیمات امضای دیجیتال پروژه لازم است. قبل از نصب روی نسخه فعال خودتان، یک بکاپ مستقل بگیرید و سورس/نصب‌کننده را در محیط آزمایشی بررسی کنید.

بعد از اجرای بیلد خودتان، از بخش پشتیبان‌گیری یک **بکاپ جدید** بگیرید. داخل پوشه آن باید `مشاهده بکاپ.html` وجود داشته باشد. بکاپ‌های قدیمی خودبه‌خود HTML جدید دریافت نمی‌کنند.

### چک سورس بدون بیلد

```powershell
node --check backup-finance-viewer.cjs
node --test test/backup-finance-viewer.test.cjs test/data-backups.test.cjs
```

در این تغییر هیچ دیتای زنده‌ای وارد، اصلاح یا بازگردانده نمی‌شود.


## اصلاحات نمایشگر بکاپ در این سورس (تقویم / معین / فاکتور / Access)

- در تمام تب‌ها روی **فیلد تاریخ یا آیکون تقویم** بزنید تا تقویم **شمسی** باز شود؛ پیمایش ماه قبل/بعد، انتخاب روز، امروز و پاک‌کردن تاریخ فعال است. فیلتر بازه فقط رکوردهای موجود در همان بکاپ را نمایش می‌دهد.
- در **حساب معین**، «نمایش با جزئیات» اکنون **جدول چهارستونی** «شرح / سایز، تعداد، فی واحد، جمع» را زیر سطر فاکتور (مطابق رابط اصلی سایت) نشان می‌دهد. مانده‌ها از موتور واقعی `CustomerStatement` ویندوز 1.0.79 می‌آیند، نه جمع دوبل بدهکار و بستانکار.
- فاکتورها در **پیش‌نمایش کامل فاکتور فروش و خدمات چاپ** با هدر، مشخصات عکاسی و سفارش، اقلام فاکتور، مبلغ نهایی، پرداختی و مانده باز می‌شوند. دکمه «چاپ فاکتور» همان صفحه را به چاپ مرورگر می‌فرستد. «PDF» هم گفت‌وگوی چاپ را باز می‌کند تا گزینهٔ **Save as PDF** را انتخاب کنید؛ این خروجی PDF سرور اصلی نیست. اگر جزئیاتی در خود بکاپ محلی ذخیره نشده باشند، نمایشگر آنها را اختراع نمی‌کند.
- در ساخت گزارش‌های Access، گزارش‌ها دیگر برای بررسی با دستور `DoCmd.OpenReport` باز نمی‌شوند؛ این مرحلهٔ غیرضروری ممکن بود پنجرهٔ مسدودکنندهٔ «Enter Parameter: تاریخ» نشان بدهد. داده‌ها و گزارش‌ها ساخته و با کوئری غیردیالوگی بررسی می‌شوند؛ **ساخت عملی در Microsoft Access روی رایانه شما هنوز باید آزمایش شود.**
- همان سورس **1.0.79** است و **هیچ نصب‌کننده‌ای بیلد نشده**. خروجی سورس را در ویندوز خودتان با `npm ci --no-audit --no-fund` و `npm run dist:unsigned` بیلد کنید. مثل قبل، ابتدا بکاپ جداگانه بگیرید.
- برای مشاهده تغییرات باید **بکاپ جدیدی از نسخه‌ای که خودتان بیلد کرده‌اید** تهیه کنید. فایل‌های HTML و Access بکاپ‌های قدیمی خودکار تغییر نمی‌کنند.
