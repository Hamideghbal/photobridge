تفاوت با بکاپ برنامه ویندوز

این خروجی شامل پاسخ‌های فعلی API حساب لابراتوار است؛ برای نگهداری سوابق و بررسی اطلاعات. ممکن است API بعضی فهرست‌ها را محدود کند. این فایل بکاپ کامل PostgreSQL یا فایل قابل‌بازیابی برنامه نیست و شامل عکس‌های اصلی، PDF، SQLite محلی، فایل Access یا فایل‌های رایانهٔ ویندوز نمی‌شود. برای بازیابی محیط ویندوز، بکاپ خود برنامه ویندوز را جداگانه نگه دارید.

فایل خروجی ممکن است اطلاعات مالی و مشخصات مشتریان داشته باشد؛ آن را در محل امن ذخیره کنید و برای افراد ناشناس ارسال نکنید. داده‌ها در مرورگر شما بسته‌بندی می‌شوند و به سرویس دیگری فرستاده نمی‌شوند.
