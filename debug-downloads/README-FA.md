# بستهٔ دیباگ PhotoBridge Lab 1.0.91

این بسته سورس آمادهٔ اجرا و ساخت محلی روی Windows x64 است. فایل نصب از پیش ساخته‌شده داخل آن نیست.

۱. Node.js نسخهٔ **22 LTS، ویندوز x64** را از https://nodejs.org/en/download نصب کنید.
۲. ZIP را کامل از حالت فشرده خارج کنید؛ فایل‌ها را از داخل پنجرهٔ ZIP اجرا نکنید.
۳. فایل **START-DEBUG.cmd** را دوبار کلیک کنید. اولین اجرا برای دریافت Electron و وابستگی‌ها به اینترنت نیاز دارد. راه‌اندازی‌های بعدی از بسته‌های نصب‌شده استفاده می‌کنند.
۴. با حساب آزمایشی وارد شوید، مسیر ذخیرهٔ عکس را روی یک پوشهٔ آزمایشی تنظیم کنید و ثبت سفارش دستی را در هر دو حالت آنلاین و آفلاین امتحان کنید. برای نگه‌داشتن عکس اصلی، روی کارت عکس حالت «کپی» را انتخاب کنید.
۵. برای خروج کامل از منوی کنار ساعت «خروج کامل» را بزنید. برنامه ممکن است با بستن پنجره در پس‌زمینه بماند.

داده‌های این اجرای دیباگ در **debug-data**، کنار همین فایل ذخیره می‌شوند. برای این اجرا پوشهٔ دادهٔ مستقل تنظیم شده است. سفارش‌های آنلاین همچنان به حسابی که وارد آن می‌شوید ارسال می‌شوند؛ برای تست از حساب و عکس آزمایشی استفاده کنید.

لاگ اجرای برنامه و مرحلهٔ نصب وابستگی‌ها در **debug-logs** ذخیره می‌شود. فایل‌های `requests-*.jsonl` فقط زمان، روش، مسیر و وضعیت درخواست‌های ناموفق محلی را ثبت می‌کنند؛ بدنهٔ درخواست، توکن و هدرها در این لاگ ثبت نمی‌شوند. ابزار توسعه هم برای پنجرهٔ اصلی باز می‌شود. برای بررسی خطا، پوشهٔ debug-logs را بفرستید؛ debug-data حاوی حساب و داده‌های محلی است و برای گزارش خطا لازم نیست.

- **RUN-TESTS.cmd**: اجرای تست‌ها با Electron و SQLite خود برنامه.
- **BUILD-UNSIGNED.cmd**: ساخت نصب آزمایشی، بدون نیاز به کلید ناشر یا GitHub Actions. این مرحله برای دریافت runtime جاوا و ابزارهای ساخت به اینترنت نیاز دارد. خروجی: `release/PhotoBridge-Lab-Setup-1.0.91-x64.exe`.

اجرای START-DEBUG پوشهٔ دادهٔ مستقل دارد، اما فایل نصب ساخته‌شده با BUILD-UNSIGNED همان شناسهٔ برنامهٔ اصلی را دارد؛ نصب آن می‌تواند نسخهٔ موجود را ارتقا دهد. برای دیباگ اولیه همان START-DEBUG را اجرا کنید.

اصلاح‌ها: پشتیبانی از ثبت گروهی عکس در حالت آفلاین، رفع پاسخ تکراری تنظیمات آنلاین، و سازگاری مسیرهای ثبت حضوری آنلاین. رفع خطای سایز استاندارد مثل `13x18` در سرور نیز در PR 760 ادغام شده است؛ فعال‌شدن آن به اتمام انتشار لیارا بستگی دارد.

اعتبارسنجی انجام‌شده: ۲۱۱ تست بسته روی Node 22 عبور کرده‌اند. سورس و رابط کاربری این بسته بررسی می‌شوند؛ اجرای واقعی این بسته روی ویندوز و ساخت EXE را شما انجام می‌دهید.
